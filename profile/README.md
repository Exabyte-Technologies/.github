# <img src="https://raw.githubusercontent.com/Exabyte-Technologies/.github/main/profile/assets/exabyte.gif" width="900" alt="Exabyte Technologies — Safer, simpler, more approachable.">

We build software and explore ideas that make technology easier to use. From personalized sound experiences to everyday management tools, our work starts with the people using it.

[Visit our website](https://exabyte.org.cn) · [Explore our repositories](https://github.com/orgs/Exabyte-Technologies/repositories) · [Contact us](mailto:contact@exabyte.org.cn)

## <img src="https://raw.githubusercontent.com/Exabyte-Technologies/.github/main/profile/assets/about.png" height="34" alt="About Exabyte">

**Our mission is to make technology safer, more convenient, and more approachable.**

We bring together software development, creative experimentation, and a belief that useful tools should be understandable. Our public projects span music and AI, Mac applications, workflow management, 3D printing, and websites.

## <img src="https://raw.githubusercontent.com/Exabyte-Technologies/.github/main/profile/assets/projects.png" height="34" alt="Selected projects">

| Project | What we're building |
| --- | --- |
| [Resona](https://github.com/Exabyte-Technologies/Resona) | An adaptive music application combining procedural audio with an AI agent for personalizing sound and interfaces. |
| [Dorm Pass Manager](https://github.com/Exabyte-Technologies/Dorm-Pass-Manager) | A system for dorm pass requests, multi-stage approvals, and kiosk or mobile sign-ins. |
| [WB App Store](https://github.com/Exabyte-Technologies/WB-App-Store) | A web-based Mac app interface for browsing, installing, and managing applications, built on [mas-cli](https://github.com/mas-cli/mas). |
| [Hivemind Print Farm](https://github.com/Exabyte-Technologies/Hivemind-Print-Farm) | A project for coordinating multiple 3D printers with optimized print queues. |
| [Exabyte Website](https://github.com/Exabyte-Technologies/Exabyte-Website) | The source for our website, introducing our mission, services, and ways to connect. |

## <img src="https://raw.githubusercontent.com/Exabyte-Technologies/.github/main/profile/assets/principles.png" height="34" alt="How we build">

- **Keep it approachable.** Favor clear interfaces and documentation that help people get started.
- **Build with care.** Treat security, privacy, and accessibility as design priorities.
- **Share and improve.** Make room for open code, feedback, and contributions from different perspectives.
